# Overview

BNB Chat Agent is an app for creating and configuring chat agents.

## Multi-agent per user

Each user can create multiple chat agents. Every agent can be configured independently with its own:

- **Skills** — specialized capabilities and behaviors
- **Tools** — actions the agent can call
- **Knowledge base** — documents and context the agent can use when answering

## How agents are used

A chat agent can be used in several ways:

1. **Directly** — chat with the agent inside the app
2. **Embedded on a website** — embed the agent widget into any site
3. **Connected to support channels** — link the agent to chat support channels such as Facebook Page Messenger
